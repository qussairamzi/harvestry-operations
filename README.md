# Harvestry Operations

Harvestry Operations is a command-line Python application for managing Harvestry Coffee's coffee inventory.

## Current Features

- View coffees
- Add coffees
- Edit coffees
- Delete coffees
- Persistent JSON storage

## Running the project

```bash
python3 main.py
```

## Technologies

- Python 3
- Git
- JSON
